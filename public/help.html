Umalator

Skill efficiency calculator for Uma Musume.

What is Umalator?

Umalator estimates how much length each skill is worth on a given uma and race setup. It runs simulations using the same engine as uma-skill-tools and reports the mean length each skill adds, divided by its base SP cost. The default sort is by Mean / Cost (efficiency), so the most cost-effective skills bubble to the top.

How simulations work

  • 500 simulations per skill are run in a single pass using browser Web Workers (parallelized to navigator.hardwareConcurrency).
  • Variance comes from skill trigger position sampling, RNG advancement between sims, and wisdom-stat activation rolls.
  • When any track field is set to a random value (mood, weather, season, ground, distance category), simulations are batched per unique combination so internal variance is preserved.
  • Results report Mean, Median, Min-Max, a Range (the spread of individual race outcomes), and a Mean CI (a confidence interval of the mean, i.e. how precisely the average is estimated). Mean / Cost is the efficiency score.
  • Set a seed in the toolbar to make a run reproducible; leave it blank for a fresh random seed each run.

Skills panel

  • Click + to add a skill. Skills are referenced by their global English name; the calculator handles ○ and ◎ variants automatically.
  • Owned: hides skills already on the uma.
  • Available: cycles between only-with-hints, only-without-hints, and off.
  • Each skill row shows the base cost, your current discount, and a trash icon to remove it.

Configs

  • A config bundles your skill list, uma settings, and track settings into one named JSON document.
  • Configs are stored in IndexedDB per browser. Edits auto-save with a 500 ms debounce.
  • The Configs dropdown lets you import, export the current one, export all, or delete the current one.
  • Use the + next to the dropdown to duplicate the active config under a new name.

Race / Uma settings

Configure the runner (stats, aptitudes, strategy, equipped skills) and the race (track, distance, mood, weather, season, ground).

  • Special value <Random> samples uniformly across all valid options for that field across simulations.
  • Distance can be set to <Sprint>, <Mile>, <Medium>, or <Long> to sample randomly within that category.

Reading results

  • Cost: base SP cost of the skill.
  • Disc: your discount; the effective cost is Cost − Disc.
  • Mean / Median: average and median length gain (m) across the simulations.
  • Mean / Cost: efficiency. The default sort key.
  • Min-Max and Range: the spread of individual per-race outcomes (Range is the central percentile band).
  • Mean CI: a confidence interval of the mean gain — how precisely the average is estimated (mean ± t × standard error). Much tighter than Range.
  • Hover any column header for a one-line explanation. Click a header to sort. Tick rows to see a selection total in the status bar above the table.

Tips

  • Configs are per-browser. Use Export → Import to move them between machines.
  • For comparing aliases / variants, add both rows and check the selection total.
  • Re-run the tour from Help → Take a Tour at any time.
